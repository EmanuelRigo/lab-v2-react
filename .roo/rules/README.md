# Roo Code — Reglas globales

Reglas que Roo Code aplica automáticamente.

## Formato

Archivo `.md` simple o con frontmatter:

```markdown
---
description: Descripción de la regla
---

# Regla

Contenido.
```

## Ejemplo

`.roo/rules/coding-style.md`:

```markdown
---
description: Estilo de código general del proyecto
---

- Usar comillas dobles
- Punto y coma obligatorio
- 2 espacios de indentación
- Nombres descriptivos para variables
```
