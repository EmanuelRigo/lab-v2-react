# Gemini Code Assist — Comandos slash

Esta carpeta está reservada para **slash commands personalizados** de Gemini.

## Formato esperado

Cada comando como archivo `.md`:

```markdown
# /nombre-comando

Descripción breve.

## Comportamiento

Qué debe hacer Gemini cuando se invoca este comando.
```

## Ejemplo

`/explain`:

```markdown
# /explain

Explica el código seleccionado de forma clara y concisa, en español.

## Pasos

1. Identificar el lenguaje y el propósito del código
2. Explicar la lógica línea por línea si es complejo
3. Mencionar posibles mejoras o issues
```

## Nota

Verificá con la documentación oficial de Gemini Code Assist si esta convención sigue vigente.
